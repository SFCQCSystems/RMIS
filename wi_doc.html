1. วัตถุประสงค์ (Purpose)

  1. เพื่อกำหนดมาตรฐานและขั้นตอนการปฏิบัติงานในการใช้งานระบบสารสนเทศ RMIS (Raw Material & Mix Tank Inspection Management System) ให้พนักงานทุกฝ่ายปฏิบัติงานในทิศทางเดียวกัน
  2. เพื่อให้การแจ้งส่งตัวอย่างตรวจวิเคราะห์วัตถุดิบรับเข้า (Raw Material) และการตรวจติดตามถังผสม (Mixed Storage Tank) มีความถูกต้อง รวดเร็ว ตรวจสอบย้อนกลับได้ครบถ้วน (Traceability) และโปร่งใสตามมาตรฐาน ISO 9001 / ISO 17025
  3. เพื่อป้องกันการสูญหายของข้อมูลการทดสอบด้วยระบบบันทึกอัตโนมัติ (Auto-Save on Back) และลดการใช้กระดาษ (Paperless Process)

2. ขอบเขต (Scope)

ครอบคลุมกระบวนการตั้งแต่การเปิดใบคำขอตรวจวิเคราะห์ตัวอย่างวัตถุดิบ, การบันทึกแบบร่าง, การตรวจวิเคราะห์ทางห้องปฏิบัติการ, การบันทึกปริมาณถังผสม (Top Up / Discharge), การลงลายเซ็นอนุมัติ 3 ระดับ ตลอดจนการพิมพ์สติกเกอร์ฉลากสินค้าและการสืบค้นประวัติย้อนกลับ

3. คำจำกัดความ (Definitions)

  • RMIS: ระบบบริหารจัดการคำขอตรวจวิเคราะห์ห้องปฏิบัติการ (Laboratory Request Management System)
  • Requester: ผู้แจ้งขอตรวจวิเคราะห์ (เจ้าหน้าที่คลังสินค้า WRM หรือ ฝ่ายผลิต)
  • QC Lab: นักวิเคราะห์หรือเจ้าหน้าที่ห้องปฏิบัติการควบคุมคุณภาพ
  • In Process: สถานะตัวอย่างอยู่ระหว่างรอตรวจหรืออยู่ระหว่างทดสอบในห้องปฏิบัติการ
  • Pass / Fail: ผลการทดสอบผ่านเกณฑ์มาตรฐาน / ไม่ผ่านเกณฑ์มาตรฐาน
  • Mixed Storage Tank: เอกสารและระบบการตรวจวิเคราะห์คุณภาพประจำถังผสม
  • Top Up / Discharge: การเติมวัตถุดิบลงถังผสม / การสูบจ่ายผลิตภัณฑ์ออกจากถังผสม
  • 3-Tier Signatures: การลงนามดิจิทัล 3 ระดับ (ผู้ตรวจสอบ -> ผู้รับรอง -> ผู้อนุมัติปล่อยผ่าน)
  • Auto-Save on Back: ระบบบันทึกข้อมูลอัตโนมัติทันทีที่กดย้อนกลับ โดยไม่ต้องกดปุ่มบันทึกด้านล่าง

6. ขั้นตอนการปฏิบัติงานโดยละเอียด (Detailed Procedures)

6.1 การเข้าสู่ระบบและการตรวจสอบสิทธิ์ (System Login & Role Verification)

  1. เปิดเว็บบราวเซอร์ Google Chrome หรือ Microsoft Edge และเข้าสู่ URL ระบบ RMIS
  2. กรอก Username และ Password ประจำตัวของตนเอง แล้วกดปุ่ม "เข้าสู่ระบบ"
  3. ตรวจสอบสิทธิ์และบทบาทของตนเองที่แถบด้านข้าง (Sidebar) ให้ถูกต้องตามหน้าที่รับผิดชอบ

6.2 การเปิดใบคำขอแจ้งตรวจวิเคราะห์วัตถุดิบ (Creating Request & Drafts)

  1. ไปที่เมนู "สร้างใบแจ้งตรวจสอบ"
  2. กรอกข้อมูลทั่วไป:
    • ชื่อลูกค้า (Customer Name) (จำเป็นต้องระบุ)
    • PO Number (ถ้ามี)
    • ทะเบียนรถ (Car Plate), หมายเลขซีล (Seal No.), หมายเลขตู้ (Container No.)
    • หมายเหตุ (Notes) (หากมีข้อกำหนดพิเศษ)
  3. ในตารางรายการสินค้า: กรอก ชื่อสินค้า (Product Name), Batch Number, และ ปริมาณ (Quantity) เช่น `10X1000L.` หรือ `18,000 KG.`
  4. หากมีหลายรายการสินค้าในรอบส่งเดียวกัน ให้กดปุ่ม "+ เพิ่มรายการสินค้า"
  5. การบันทึกข้อมูล:
    • ส่งใบแจ้งทันที: กดปุ่ม "ส่ง" ด้านล่าง -> ระบบส่งข้อมูลไปยังห้องแล็บพร้อมเสียงเตือน Realtime Chime
    • ระบบบันทึกอัตโนมัติ (Auto-Save on Back): หากผู้ใช้กรอกข้อมูลหรือแก้ไข แล้วกดปุ่ม "ย้อนกลับ" ที่มุมบนขวา ระบบจะทำการตรวจจับและบันทึกข้อมูลลงฐานข้อมูลโดยอัตโนมัติทันที พร้อมแสดงข้อความแจ้งเตือน "บันทึกข้อมูลอัตโนมัติเรียบร้อยแล้ว"
    • บันทึกแบบร่าง: กดปุ่ม "ร่าง" เพื่อเก็บไว้ในเมนูแบบร่างสำหรับแก้ไขต่อในภายหลัง
💡 คุณสมบัติใหม่: ระบบบันทึกอัตโนมัติเมื่อกดย้อนกลับ (Auto-Save on Back)
ระบบมีอัลกอริทึมตรวจสอบความเปลี่ยนแปลงของข้อมูล (Dirty Checking) หากมีการแก้ไขค่า Density, RM No., ผลตรวจ หรือข้อมูลสินค้า เมื่อกดปุ่ม "ย้อนกลับ" ระบบจะเซฟข้อมูลอัตโนมัติทันที ป้องกันข้อมูลสูญหาย 100% โดยที่ผู้ใช้ไม่ต้องเลื่อนลงไปกดปุ่มบันทึกด้านล่าง

6.3 การบันทึกผลวิเคราะห์ทางห้องปฏิบัติการ (QC Lab Testing & Recording)

  1. เจ้าหน้าที่แล็บตรวจรับตัวอย่างจริง และเปิดใบแจ้งตรวจสอบที่สถานะเป็น Pending
  2. กดปุ่ม "แก้ไข" เพื่อลงผลการวิเคราะห์:
    • ระบุรหัส RM No. ของวัตถุดิบ
    • กรอกค่าความหนาแน่น Den@15C และ Den@30C
    • ระบุผลการทดสอบ: Pass (ผ่านเกณฑ์), Fail (ไม่ผ่าน), หรือ In Process (อยู่ระหว่างทดสอบ)
  3. เมื่อผลตรวจผ่านเกณฑ์ครบทุกรายการ จึงจะสามารถปรับสถานะภาพรวมเป็น "Complete" ได้
  4. กดย้อนกลับ (เพื่อเซฟอัตโนมัติ) หรือกดปุ่ม "บันทึก"

6.4 การจัดการเอกสารการตรวจวิเคราะห์ประจำถังผสม (Mixed Storage Tank)

  1. ไปที่เมนู "ใบตรวจ Mix Tank" แล้วกดปุ่ม "+ สร้างใบตรวจ Mix Tank"
  2. ระบุชื่อถังจัดเก็บ เช่น T-01, T-02, MIX-A พร้อมระบุวันที่และเวลา
  3. บันทึกสมดุลปริมาณถังผสม (Volume Tracking):
    • BEFORE BALANCE: ปริมาณคงเหลือก่อนหน้า
    • TOP UP: ระบุวัตถุดิบที่เติม, Lot No., ปริมาณ (KG/L), Supplier, และทะเบียนรถ
    • DISCHARGE: ระบุปริมาณที่สูบจ่ายออก และเลขที่เอกสารสูบจ่าย
    • ระบบจะคำนวณ AFTER BALANCE โดยอัตโนมัติ:
      ปริมาณคงเหลือสุทธิ (After) = ปริมาณก่อนหน้า (Before) + ยอดเติม (Top Up) - ยอดจ่าย (Discharge)
  4. บันทึกผลตรวจทางกายภาพและเคมี: Density, Temperature, Appearance, Color

6.5 การตรวจสอบและลงนามดิจิทัล 3 ระดับ (3-Tier Digital Signatures)

ระดับการลงนาม ตำแหน่งรับผิดชอบ หน้าที่และการตรวจสอบ
ระดับที่ 1: ผู้ตรวจวิเคราะห์ QC Lab Analyst ตรวจสอบการคำนวณปริมาณ และผลการตรวจวัดคุณสมบัติทางกายภาพ/เคมี
ระดับที่ 2: ผู้ตรวจสอบ QC Supervisor ทบทวนความถูกต้องของข้อมูลเทียบกับ Spec มาตรฐานของบริษัท
ระดับที่ 3: ผู้อนุมัติปล่อยผ่าน QA/QC Manager พิจารณาอนุมัติขั้นสุดท้ายเพื่อปล่อยผลิตภัณฑ์ (Approved) ให้ใช้งานได้
  1. ผู้มีหน้าที่รับผิดชอบในแต่ละระดับกดปุ่ม "ลงลายเซ็น"
  2. ระบบจะดึงภาพลายเซ็นอิเล็กทรอนิกส์จริง พร้อมระบุชื่อ-นามสกุล และเวลาที่เซ็นจาก TimeSync ของเซิร์ฟเวอร์โดยอัตโนมัติ

6.6 การพิมพ์รายงานผลและการพิมพ์สติกเกอร์ (Print Report & QC Stickers)

  1. การพิมพ์รายงานเอกสารการตรวจวิเคราะห์ประจำถังผสม: กดปุ่ม "พิมพ์เอกสาร / Print" เพื่อออกรายงานขนาด A4 ที่มีลายเซ็นครบถ้วน 3 ฝ่าย
  2. การพิมพ์สติกเกอร์รับรองผล (QC Label): ในหน้ารายละเอียดใบแจ้งคำขอ ให้กดปุ่ม "พิมพ์สติกเกอร์" เพื่อสั่งพิมพ์ฉลากออกทางเครื่องพิมพ์สติกเกอร์ความร้อนสำหรับนำไปติดที่ถังหรือบรรจุภัณฑ์

7. ข้อควรระวังและการควบคุมความเสี่ยง (Precautions & Risk Controls)

ความเสี่ยง / ข้อควรระวัง มาตรการควบคุมและวิธีปฏิบัติที่ถูกต้อง
ข้อมูลสูญหายขณะออกจากหน้าจอ ระบบมี Auto-Save on Back เมื่อกดย้อนกลับ ระบบจะบันทึกข้อมูลให้อัตโนมัติทันที ป้องกันการปิดหน้าต่างโดยไม่ตั้งใจ
การปรับสถานะ Complete ผิดพลาด ระบบล็อกไม่อนุญาตให้เปลี่ยนสถานะเป็น Complete หากยังมีรายการวัตถุดิบค้างสถานะ In Process อยู่
เลขที่ใบแจ้งซ้ำกันในรอบปี ระบบควบคุมไม่ให้เลขที่ใบแจ้ง (Request No) ซ้ำกันในรอบปี ค.ศ. เดียวกัน แม้จะใช้สิทธิ์ Admin แก้ไขตัวเลข
เครือข่ายอินเทอร์เน็ตโรงงานขัดข้อง ระบบทำงานแบบ Progressive Web App (PWA) มี Service Worker ช่วยแคชหน้าจอ ทำงานแบบ Offline ได้อย่างต่อเนื่อง

8. เอกสารอ้างอิงและบันทึกคุณภาพ (Related Documents & Quality Records)

  1. เอกสารคำขอตรวจวิเคราะห์คุณภาพทางห้องปฏิบัติการ (Laboratory Request Record)
  2. เอกสารการตรวจวิเคราะห์ประจำถังผสม (Mixed Storage Tank Inspection Record)
  3. สติกเกอร์รับรองผลการตรวจวิเคราะห์คุณภาพ (QC Approved Label)
  4. คู่มือการใช้งานระบบ RMIS ฉบับสมบูรณ์ (RMIS User Manual)
